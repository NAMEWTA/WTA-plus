## Q3 假设与反例

- objective_id: OBJ-09
- bloom_level: evaluate

- difficulty: hard

课的隐含假设若反转，合格读者会把哪根箭头画反？

1. **若信 http README。** 读者会让 domain 依赖 `platform-http`，或把 `HttpClient` 搬进 http 包（课反例 3）。工作树否决：domain 只见 contracts；唯一消费者是 adapter。课把冲突张开，口诀不迎合 README。此假设课内已挡。
2. **若见厅堂用了 HTTP，就给 App 加 `platform-http`。** 课反例 2。磁盘：两厅堂都不声明该包；`isHandledError` 经 adapter 再导出。此假设课内已挡，再导出这一跳课没写。
3. **若把 `superadmin` / 遗留 `admin` 当成 `*:*:*`。** 源码：`isSuperAdmin` 只喂 `hasRole*`；`hasPermission` 只认权限数组或 `ALL_PERMISSIONS`。角色超管 **不会**自动放行权限串。课表分行写了，误区没点破「超管角色 ≠ 全部权限」。
4. **若把「抛错就 logout」算成 `restoreProtectedNavigation` 的函数体。** 平台函数只编排四步；logout 是 App `catch`。读者会在 platform 包里找 `SessionPort`（那是 auth 的 `requestRelogin` 才注入的）。
5. **若以为 `resolve({ domainId })` 会拒绝「键在 A domain、却用 B domainId 来查」。** 源码按键命中即返回。`assembleServerRoutes` 用 `inferDomainId(componentKey)` 填这个字段，主要给缺失键诊断，不是所有权闸。
6. **若见厅堂 `package.json` 有 `"axios": "catalog:"`，就说厨房也可以 import axios。** 课类比失效处已写；`host/download.ts` 仍 `import axiosModule from 'axios'`。这是厅堂壳存量，不是 domain 许可证。terminal-purity 抓的是 domain/platform。

读完后仍说得出：规格纸在 contracts，事故单在 http，插头在 adapter，电工在 App；App → platform 是一等边；App 不声明 `platform-http`。仍说不清（若格子=每个 export）：`handleCallback` 失败先清 storage；`resolve` 不校验 domainId；超管角色不管权限串。
