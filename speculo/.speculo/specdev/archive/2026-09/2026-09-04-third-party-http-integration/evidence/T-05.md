## Implementation

Provider and endpoint credentials are separate records. Endpoint credentials override provider credentials by type. AES-GCM ciphertext, nonce, auth tag, and key version are persisted; only the supported `v1` envelope is accepted and unknown versions fail closed. The master key is read only from configuration. Management responses expose summaries and never plaintext or ciphertext. Logically deleted credentials cannot be reactivated through a forged identifier.
