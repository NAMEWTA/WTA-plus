## 1. 实现摘要

新增唯一 Spring Boot 自动配置入口，在 `openapi.enabled=true` 时装配真实 Handler registry、签名器、Redis nonce/双限流、Sa-Token 机器 Session bridge/invalidator、事件发布器和 Servlet gateway filter。开关缺失或为 false 时上述 Bean 均不注册；管理 Controller 继续消费既有相同条件，不产生关闭态入口。

启用态启动校验要求 32-byte 标准 Base64 KEK、合法 KEK version、正数时间窗口与限额，并依赖唯一 credential/authorization SPI、Redis、Sa-Token 和 MVC mapping。缺失、重复或无效均阻止启动，错误指出配置键或缺失类型但不回显 key material。Filter 只处理 REQUEST、禁用 async，位于 Sa-Token context 之后且不改变普通请求。

admin 配置只新增 `OPENAPI_*` 环境变量占位符，默认 `OPENAPI_ENABLED=false`，KEK/version 默认空。模块 README 与父仓 customization map 记录迁移、配置、菜单、双 UI、回滚及生产批准点；未写入真实 secret，未执行迁移或启用。
