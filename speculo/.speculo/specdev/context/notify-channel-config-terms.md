# 通知渠道配置术语

- **Status:** Current
- **Date:** 2026-09-10
- **Source:** `2026-09-10-notify-channel-config` CONTEXT

控制面术语。数据面 Notify Channel / Provider / 投递日志仍见 `oss-direct-notification-terms.md` 与 ADR-0006。本文件不覆盖那些数据面定义。

**通知配置**：通知中心下的渠道配置管理入口；单一菜单，页内 TAB 切换邮件配置与短信配置。
_Avoid_: 文件配置管理、系统参数 `sys_config`、隐藏在通知监控下的子路由、两个独立菜单

**渠道账号**：某一渠道下可独立启用或停用的 SMTP 或短信供应商配置，包含凭据与发件身份；允许同时启用多个账号。
_Avoid_: OSS 式唯一默认、隐式默认发件人、YAML `mail.enabled` 渠道总开关

**发送路由**：发送时必须根据场景与渠道解析到明确的渠道账号；短信还依赖该账号下的供应商模板码，邮件还依赖该账号的发件人。
_Avoid_: 无绑定则使用第一个启用账号、把故障切换或灰度当作本期路由

**配置权威**：邮件与短信的运行时账号、场景文案、配额与收件人拦截只以数据库为准。YAML 不再留存发件人、供应商账号、`restricted` / `minute-max` / `account-max`。SMS4J 线程池等进程项可以留在 YAML。
_Avoid_: YAML 占位并行权威、Nacos 作为邮件短信账号源、双读 DB 与 YAML、全局号码限额

**逻辑场景**：由代码播种的稳定场景编码；管理员不能增删场景。管理员可改该场景的邮件文案，并绑定渠道账号与短信供应商模板码。
_Avoid_: 模板市场、管理员新建任意场景、把 sceneCode 当成供应商模板号

**变量契约**：短信供应商模板或代码模板一旦确定，变量名随之确定并随编码进入程序。管理端不能改名、新增或删除必填变量。
_Avoid_: 运营自定义变量名、自由占位符、把调用方 title/content 字符串当成变量 schema

**渠道绑定**：逻辑场景在每个渠道上绑定唯一渠道账号；短信再绑定该账号下的供应商模板码。普通调用方不传 providerKey。绑定缺失或账号停用则该渠道失败关闭，不改选其他账号。
_Avoid_: 独立路由表、调用方传供应商、故障切换、无绑定则用任意启用账号

**测试发送**：管理页提供账号级试发（验证 SMTP/厂商凭据）和模板级试发（用样例变量走真实渠道绑定）。
_Avoid_: 只靠生产流量验证启停

**发送内容权威**：MAIL/SMS 真正发出的内容来自通知配置中的场景模板与调用方变量；intent 保存渲染快照供审计。调用方不再携带硬编码正文，只传变量值。
_Avoid_: 配置页只是默认值、调用方覆盖模板正文、Java 里再写一份短信/邮件句子

**变量占用位置**：代码播种变量清单只读展示。邮件用只读 token（`${name}`）表示占用位置；短信用参数映射表，不提供自由正文。
_Avoid_: 运营新增变量名、把短信页做成自由短信编辑器

**收件人拦截**：每个逻辑场景的 MAIL/SMS 绑定各自配置是否启用拦截、每收件人每分钟条数、每收件人每天条数。短信按手机号计，邮件按邮箱计。
_Avoid_: 全局 minute-max、所有场景共用一套号码限额

**账号发送配额**：每个邮件或短信渠道账号有每分钟发送上限。短信逻辑场景绑定可以设置更细的每分钟条数，且不得超过所属账号上限。与「单手机号每分钟收几条」不是同一件事。
_Avoid_: 只用 YAML 全局 minute-max 当厂商账号配额、无绑定则共用一个全局计数器

**包装模板**：`notice-published` 与 `workflow-task` 的 MAIL/SMS 模板是外壳。配置页可改前后文，必须保留已声明变量（如 `${title}` `${content}` `${path}`）。
_Avoid_: 业务正文直接当邮件发出、取消公告/流程自定义正文、把运行时 title/content 当成可改的变量名

**首期逻辑场景**：`auth-captcha`、`person-rebind`、`enterprise-transfer`、`workflow-task`、`notice-published`。demo 与 `login-welcome` 不进入本期邮件/短信 TAB。
_Avoid_: 空白模板市场、把站内信登录欢迎纳入本期 TAB
