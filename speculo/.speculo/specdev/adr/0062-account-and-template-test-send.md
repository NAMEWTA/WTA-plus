# ADR-0062: 管理页提供账号级与模板级测试发送

- **Status:** Accepted
- **Date:** 2026-09-10
- **Source:** `2026-09-10-notify-channel-config` ADR-008（LOG-014）

## Context

没有隐式默认账号后，启停是否可用不能靠生产流量验证。

## Decision

通知配置提供两类测试发送：账号级验证 SMTP 或短信厂商凭据；模板级用样例变量走该场景的真实渠道绑定。测试发送使用独立权限，结果进入投递监控。

## Consequences

测试发送不得绕过账号停用、绑定缺失和变量契约。样例变量只能使用该场景已声明的变量名。
