# 账户档案与实名认证

**账户**：现有系统用户，以全局 `userId` 标识；个人或企业实名认证申请只能绑定到发起申请的账户自身。
_Avoid_: 把档案主键、Client 主键或工作流实例当作账户标识

**个人档案**：承载自然人实名资料及其材料归属的独立业务聚合，并通过有效绑定关联到账户。
_Avoid_: 直接把实名材料字段追加到系统用户表

**企业档案**：承载企业主体资料及其材料归属的独立业务聚合，并通过有效绑定关联到账户。
_Avoid_: 把企业资料或企业主键写入系统用户表

**认证审核**：个人或企业档案申请交由现有 ruoyi-workflow 流转；档案模块拥有申请与绑定语义，工作流模块拥有流程定义、任务和实例。
_Avoid_: 在档案模块自建待办表或直接查询工作流内部表

**档案材料**：归属于某一个人或企业档案业务记录的文件引用；文件实体仍由系统 OSS 能力拥有。
_Avoid_: 在档案表复制文件二进制或把公开 URL 当作唯一归属证据

**材料分类目录**：profile 自有的受限三层材料目录；一级固定区分个人、企业、通用，可直接挂标签或增加一层二级分类后再挂标签。分类与标签节点由 nodeType 区分，每个节点只有一个 parentId，复用菜单/部门树范式但不依赖 system 内部实体。
_Avoid_: 无限层级、标签属于多个分类、把档案分类写入 system 菜单/部门表，或用自由文本代替受控目录

**材料标签绑定**：每个档案材料引用必须通过 profile 自有绑定关系选择一个启用的标签叶子，分类层级负责组织，绑定关系负责材料归属。已引用标签可停用但不可物理删除，历史材料保留标签名称快照。
_Avoid_: 无标签材料、一次材料选择多个标签、选择分类节点，或用分类名称字符串代替稳定关系

**系统必传标签**：由 DML 预置并标记 systemRequired 的稳定材料标签 code，供个人证件类型和企业办理规则引用；管理员只能调整显示名称和排序，不能改码、停用或删除。
_Avoid_: 按可变显示名称校验必传材料，或让运营配置意外解除认证规则

**材料集合限制**：一个当前申请工作副本或管理员直建档材料集合最多包含十个 JPEG、PNG 或 PDF 文件，每个文件最大 10 MiB；服务端以 OSS 元数据、扩展名和 MIME 校验，历史提交快照和旧档案版本不占用当前集合名额。
_Avoid_: 把 10 MiB 解释为全部文件累计大小，信任客户端声明，或允许其他文件类型绕过服务端校验

**工作副本材料移除**：草稿或退回工作副本可解除材料的当前关系并释放十份文件名额，但 profile 保留 detached 审计且不删除 OSS；已进入不可变快照或 ADMIN_CREATE 版本的材料不可移除。
_Avoid_: 从历史快照删除材料，或把解除当前关系实现为删除底层对象

**认证申请快照**：一次个人或企业认证提交时冻结的字段和材料集合；待审快照不覆盖当前有效档案，历史快照不随档案后续变化而重写。
_Avoid_: 把待审表单直接当作当前有效档案

**有效绑定**：认证流程完成后发布的账户与个人/企业档案关系；同一账户可同时拥有一条个人有效绑定和一条企业有效绑定。
_Avoid_: 用流程实例存在、申请已提交或系统角色推断已认证

**认证供应商**：实现个人或企业外部核验策略的可替换适配器，以稳定 providerCode 注册；首期人工复核也是一种默认策略。
_Avoid_: 把支付宝、微信、微警等供应商字段写入档案核心模型

**证件类型**：自然人用于实名认证的法律证件类别；地区不是证件类型，同一地区可能存在身份证件、居住证或通行证等不同规则。
_Avoid_: 用“港澳台”一个枚举值承载多种号码格式和材料要求

**区域证件目录**：由服务端控制的中国大陆、香港、澳门和台湾具体证件类型集合，分别定义号码规则、公共字段和必传材料；包含上述地区签发的护照或旅行证件，其他国家或地区不属于首期。
_Avoid_: 用一个“港澳台”值合并不同证件规则，或允许请求自行声明证件规则

**档案版本**：某次认证完成或管理员修订后发布的个人/企业身份事实版本；当前版本可被新版本替代，但历史版本和来源不重写。
_Avoid_: 直接覆盖当前行而无法还原认证时的字段

**管理员覆盖决定**：具备独立高风险权限的运营人员绕过普通审核路径作出的直接通过、拒绝、字段修订或状态处置，必须记录原因、操作者、来源和前后值。
_Avoid_: 把管理员直接操作伪装成普通 workflow 任务完成

**管理员直接建档**：具备高风险权限的运营人员在没有用户申请和 workflow 的情况下首次建立个人或企业身份事实，并可选择向合格账户发布绑定。
_Avoid_: 把直建记录伪装成用户申请，或绕过身份唯一性和绑定基数

**ADMIN_CREATE 来源快照**：管理员直接建档时冻结的首次核心字段、必传材料、操作者、原因和时间；它不是认证申请或 workflow 记录，但与首个档案版本共同永久保留。
_Avoid_: 只写当前档案行而不保留首次创建证据，或伪造申请人与流程历史

**绑定状态探测**：已登录申请人输入个人证件信息或企业统一社会信用代码时，只能得到是否已被其他账户绑定的状态，不回显任何个人、企业、负责人或材料字段；申请人始终自行填写完整实名认证资料。
_Avoid_: 通过身份键预填旧档案、暴露主体详情，或把查询命中当成已认证

**档案注销**：使个人或企业档案退出当前有效主体集合的逻辑删除动作；旧档案、绑定、版本和材料永久保留且不能恢复为 current，再次认证创建带 previousProfileId 的新档案。
_Avoid_: 物理删除档案证据、恢复已注销档案，或把注销等同于仅解除账户绑定

**个人本人解绑**：当前账户解除自身 active 个人档案绑定的即时命令；它立即使个人认证失效但不注销档案，不能一键恢复，账户必须重新认证才能再次取得有效绑定。
_Avoid_: 由本人注销主体档案、删除历史证据，或把解绑当作可撤销开关

**未绑定个人档案认领**：任一正常账户对未注销且 unbound 的个人档案重新提交完整身份字段、材料并通过认证审核后，复用该档案发布新版本和 active 绑定；原账户没有免审核优先权。
_Avoid_: 仅凭证件号认领、复制旧字段作为申请资料，或允许原账户一键恢复

**已绑定个人档案换绑**：仅个人档案允许新账户通过完整重新实名认证申请替换其他账户的 active 绑定；企业 active 负责人只能按专用负责人转移、先解绑后重新认证或管理员 override 处置。
_Avoid_: 将普通企业实名认证作为负责人转移入口，或在个人重新认证完成前立即解除旧绑定

**旧绑定手机号提示**：已登录个人申请人填写完整身份字段并精确命中其他账户的 active 绑定后，可看到旧账户 system 手机号掩码；普通绑定探测不返回手机号，任何接口都不返回旧账户完整号码或其他资料。
_Avoid_: 通过证件号枚举手机号、展示完整号码，或在日志中保存手机号明文

**个人换绑意图**：申请人明确确认后冻结进个人认证提交快照的 rebindIntent、profileId 和旧 bindingVersion；它不立即改变旧绑定，只允许认证最终通过时在版本校验后原子切换。
_Avoid_: 把页面确认当成已经换绑，或让驳回、撤销、终止申请影响旧账户

**个人换绑通知**：个人绑定原子切换完成后，通过统一通知能力向旧账户当前 system 手机号和可用站内渠道发送的安全变更通知；发送失败不回滚绑定，但必须可审计、可重试。
_Avoid_: 在通知中包含证件号、新账户或材料信息，或把外部渠道成功作为绑定事务提交条件

**活动身份唯一性**：身份证明号码和统一社会信用代码只在未注销档案及进行中申请范围内唯一；逻辑注销记录不阻止同一身份重新认证，但新旧档案使用不同 ID 并保留前后继关系。
_Avoid_: 删除旧记录以复用身份键，或允许同一身份同时存在多个未注销档案

**管理员直建个人绑定**：person override 管理员可将 ADMIN_CREATE 个人档案直接绑定到正常启用且没有 active/suspended 个人绑定的账户，无需短信或既有个人认证；创建快照与绑定在同一事务完成。
_Avoid_: 绕过账户状态和绑定基数，或把本次 ADMIN_CREATE 误判为目标必须预先具备的个人认证

**注销档案视图**：管理列表通过状态筛选访问的已注销个人或企业记录，详情可查看全量版本、材料、绑定历史及档案前后继链，但所有档案与绑定操作保持只读。
_Avoid_: 默认混入活动档案列表、隐藏历史证据，或提供编辑、恢复和重新绑定入口

**绑定状态**：账户与档案之间关系的业务状态，独立于认证申请状态和档案版本状态；解绑、停用和恢复不得删除历史关系或材料。
_Avoid_: 用删除绑定行表达注销，或用申请状态推断当前绑定是否有效

**企业认证负责人**：当前通过有效绑定控制企业档案的唯一系统账户；不等同于企业法定代表人，非法定代表人可依据授权材料取得该身份。
_Avoid_: 通过姓名或法定代表人证件号自动匹配 sys_user

**负责人转移**：当前企业认证负责人通过目标实名姓名、认证证件号后四位、绑定手机号和目标手机验证码，将有效绑定原子切换至合格目标账户的自助命令，不是新的企业认证或工作流审批。
_Avoid_: 覆盖旧绑定行、向请求提供的任意手机发送验证码，或让非当前负责人发起转移

**负责人转移挑战**：绑定当前负责人、企业、目标账户和目标手机号的一次性短信验证意图；验证码成功后才能消费挑战并切换绑定。
_Avoid_: 复用登录验证码 key，或只按手机号保存一个可用于任意企业的验证码

**实名认证证件号后四位**：目标账户当前 active 个人档案中认证证件号码规范化后的最后四个字符，适用于大陆及港澳台全部首期证件类型。
_Avoid_: 把负责人转移限制为大陆身份证，或把证件片段作为查询结果返回

**提交快照版本**：同一认证申请每次提交时固化的递增、不可变字段与材料版本；退回或撤销只允许修改工作副本并产生下一版本。
_Avoid_: 重提时覆盖上一轮审核实际看到的字段或材料

**能力权限**：以一项可完整完成的用户业务能力为授权单位；个人和企业分别拥有 apply、query、material、review、manage、override 能力。
_Avoid_: 把内部读取、校验或流程终止拆成必须额外分配的隐藏伴随权限

**材料标签管理权限**：个人和企业共享的 profile 级材料目录 query/manage 能力；申请人通过对应 apply 能力读取可选择标签，不需要后台目录权限。
_Avoid_: 为个人和企业复制两套标签管理权限，或要求申请人额外取得后台查询权限
