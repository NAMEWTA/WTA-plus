# CRUD 开发能力

**CRUD 标准模板资产**：`docs/fm` 中供 AI 与开发者参考的 Java、前端、XML 和 SQL 静态模板及注意事项；它不进入产品运行时，也不提供在线生成接口。
_Avoid_: 运行时模板、低代码生成器

**运行时代码生成器**：由后端 ruoyi-gen、前端 gen domain/web-domain、tool/gen 接口与菜单、gen_table 元数据共同组成的在线低代码能力；本 change 的目标是将其完整退役。
_Avoid_: CRUD 标准模板资产

**基座硬退役**：在尚无生产兼容义务的项目基座中，直接删除废弃能力的源码、合同、权限和专属数据结构，不建立兼容入口、数据归档或回滚恢复机制。
_Avoid_: 生产兼容迁移、滚动退役
