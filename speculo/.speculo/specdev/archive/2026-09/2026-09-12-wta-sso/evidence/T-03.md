## What the tests drive (shipped `SsoAuthorizationService` / `PkceS256` / `SsoTokenExtras`)

- Authorize from **empty challenge** / `plain` / wildcard redirect / unlisted redirect / missing state → reject (does not start after a code is issued).
- Happy path: authorize → exchange with RFC 7636 sample verifier → `issued.clientId` = admin business client, **not** `sso`.
- Wrong verifier, reused code, expired code, rebound client_id, rebound redirect_uri → reject.
- Concurrent exchange: at most one success.
- `revoke` removes only the submitted token.
- `SsoTokenExtras.bind` writes `LoginHelper.CLIENT_KEY` extra = business clientId and throws on clientKey `sso`.
