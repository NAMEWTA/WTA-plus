## 1. 实现摘要

system domain 新增 reset candidate 与 temporary password 的领域模型、严格 transport narrowing 和 `no-store` POST 请求接缝；未知、空密码或非正 TTL 均失败关闭，页面不接触 OpenAPI transport。SystemWebRuntime 新增最小 password-policy/validator 与 clipboard ports，Admin manifest registry 从 T-06 `identityAccessService` 显式注入，不建立 web-domain 到 domain-admin 的反向依赖。

用户新增页改用既有 `/system/user/` 响应中的服务端合规候选并复用公开策略，删除 `sys.user.initPassword` UI 读取和 5–20 静态规则。永久重置改为先取候选、可编辑、确认、逐项校验后再提交；临时密码用独立 `system:user:temporaryPassword` 权限，成功后在当前 modal 生命周期一次展示 60 秒提示与复制按钮。关闭、取消、过期请求、失败和成功都会清空敏感 refs，不写 store、localStorage、日志或 telemetry。
