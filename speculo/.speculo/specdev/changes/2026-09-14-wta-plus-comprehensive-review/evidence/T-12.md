## 输入与实现

- `T-12-input-checkpoint.json` 核对上游 197 个路径。最终 `T-12-checkpoint.json` 记录本票 44 个路径；上游除本票授权重叠路径外无 hash 漂移。不存在本票删除文件。
- Admin/Home 以 `identityLoaded`、`navigationLoaded` 和会话代次表达恢复状态；空角色为合法已加载身份，Admin 不再补造 `ROLE_DEFAULT`。同一身份恢复共用一次 promise；过期身份/菜单响应不能继续注册或替换路由。
- 两 App 保存实际 `router.addRoute` 返回的移除回调。退出回收动态路由与投影，保留静态路由；注册前拒绝重名覆盖。真实 DML 中档案目录为 `profile`，其路由名 `Profile` 与旧静态个人中心冲突；静态个人中心 route/SFC 同步为 `AccountProfile`，URL 仍为 `/user/profile`，保留 KeepAlive 名称匹配。
- logout 合并重复调用，远端请求上限 10 秒。失败、超时和 401 均执行本地 finally：token、昵称/ID/角色/权限、路由、待处理 HTTP 清理；Admin 还关闭 Push/SSE、通知、页签和 iframe 缓存。Home 原有 token finally 被保留，不报告其此前存在 token 残留。
- Axios facade 为调用时的请求范围附加 AbortSignal；`cancelPending` 取消旧范围并建立新范围。被取消及取消后迟到的响应作为已处理取消拒绝，不触发 401 恢复或错误弹窗。domain 认证代次阻止退出后的迟到登录安装 token；旧 logout 不清除随后登录的新 token。
- `requestRelogin` 在远端退出失败时仍执行登录导航，并释放 single-flight。导航恢复的 `navigationPending` 与弹窗 `show` 独立，避免 Home 初次身份 401 留下竞争弹窗，也避免旧导航 finally 覆盖退出流程状态。
- 两个退出 UI 在远端失败后仍导航离开受保护页面。没有提示服务端 token 已撤销；本地退出不等于远端撤销成功。

3. 默认首轮 42 pass/9 fail/1 skip：旧加密头断言、未提供消息/运维配置、Notify 两个字典 fixture 缺失、真实 Profile 名称冲突、旧工作流 URL Bearer 断言。依照当前源码修正测试接缝与静态名称，不恢复已退役凭据包装、不向 URL 放回 token。第二轮 50 pass/1 fail/1 skip 为异步验证码观察；保留完整请求顺序断言并等待，第三轮 51 pass/1 skip。工作流 iframe 仍是 HTML fixture，真实设计器认证和消息来源安全不由这个测试背书。
4. 真实 HTTPS 首轮点击注册时验证码准备未完成，未发出注册请求；补等待真实 `/auth/code` 完成后 6/6 通过。源码显示注册页在验证码就绪前将 context 置 available，这是 T-13 应修的 UI 就绪缺口，未在 T-12 将其伪报为产品已修。
