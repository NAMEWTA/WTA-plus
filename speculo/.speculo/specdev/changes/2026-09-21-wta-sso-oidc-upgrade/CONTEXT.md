# WTA 统一认证

**WTA SSO**：基于现有系统账户提供统一身份认证的服务；内部 App 和外部平台以同一 OIDC 协议接入。
_Avoid_: 内部专用登录协议、另建 SSO 用户体系。

**统一账户**：由现有 sys_user 及 sys_* 关系拥有的账户。经 SSO 注册产生的账户仍由现有系统用户管理功能按权限管理。
_Avoid_: SSO 影子用户、第三方专属密码库。

**SSO 托管界面**：由 sso-web 提供的默认登录注册与认证交互界面，应用可通过浏览器跳转使用。
_Avoid_: 业务 App 共享登录 Cookie。

**自定义认证界面**：由 App 或第三方构建、接入 WTA SSO 统一认证流程的登录注册界面。自定义呈现不改变账户真相源和最终 OIDC 接入合同。
_Avoid_: 自定义 UI 即独立用户库、自定义 UI 即密码 grant。

**账户可管理**：具备相应用户管理权限与数据范围的管理员可以查询和管理 SSO 注册的系统账户。账户被管理不代表账户本人拥有管理后台权限。
_Avoid_: 注册即管理员、统一账户即所有 Client 自动准入。
