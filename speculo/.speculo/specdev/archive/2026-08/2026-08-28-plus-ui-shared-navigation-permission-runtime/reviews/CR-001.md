### 标准轴补充说明

推荐的菜单边界不是公共 Store，也不是让 Platform 依赖 Vue Router。更合适的所有权是：

```text
HTTP/JSON unknown
  -> domain-admin 递归校验 ServerMenuNode
  -> platform-app-runtime 纯投影
  -> Admin 显式适配 RouteRecordRaw
  -> navigation Store 保存 App 自有投影
```

`ParentView` 默认键仍带有 RuoYi RouterVo 协议色彩，但当前展平为 opt-in、键可覆盖，且各 Vue Web App 预期消费同一后端菜单协议。本次仅记为观察项，不构成 finding；未来若接入不同菜单协议，应由调用方显式提供键或移除默认值，不能继续泛化为所有 App 的导航公理。

### 权限指令时序证据

当前实现：

```text
Vue hostInsert(element)
  -> directive mounted
       -> requireValues 可能 throw
       -> requireEvaluator 可能 throw
       -> 只有正常求值且拒绝时 removeChild
```

因此“抛错”不等于“失败关闭”。后端仍是最终鉴权者，故该问题不等同于服务端越权，但它违反了已锁定的前端可见性合同，并会让公共 Web Kit 的 future consumer 在缺失身份时显示本应隐藏的控件。

最低满足行为应为：

```text
invalid binding / missing evaluator
  -> remove element
  -> throw stable error
```
