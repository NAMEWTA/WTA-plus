## 实现与边界

TestTree 保持 classic 和现有 Controller/权限/Log/DTO 合同。新增、更新、删除进入 DSTransactional：按实际父边定位树根并排序加锁，锁后 current read 重验父链；根值必须显式为 0，拒绝不存在/已删除/负数/空父、自父与后代父。已有坏链或环不允许继续扩展。当前节点、变化的新父节点及新增父节点通过既有 DataPermission 查询；内部结构检查包含隐藏祖先/子节点，不向 HTTP 返回隐藏数据。名称不增加唯一约束。

批删先去重、验证所有节点可见，再检查所有直接子节点（含不可见子节点）；带子节点整批拒绝，isValid=false 不能跳过完整性或权限。写入数量不符或 SQL 故障触发整笔事务回滚。移除原空校验/TODO，未增加无业务事实的普通 TestDemo 规则。六文件基座只为 test_tree 新增 parent_id 索引，未改在线 schema；现有数据库应用该变化需要另行交付，不在本票操作。

classic Service/Mapper/XML 模板同步无 ancestors 与含 ancestors 两种树；路径从真实父链生成，移动时在同事务校验并更新后代。经典普通表 XML 现在生成对应的空 Mapper，不误用 layered Row 合同。上下文明确真实父列索引、资源权限配置和 FreeMarker dollar 插值模式，保留 MyBatis #{...}。新测试用真实引擎生成 9 个 Java 和 3 个 XML，编译后在独立 JVM 将生成目录置于 classpath 首位，断言 Service 确实加载自生成目录；借用现有 Entity/BO/VO 和表结构，未修改 System 实现。

前端源码核对：TreePage 顶级选项 id=0，顶层新增明确 parentId=0；编辑提交真实父值，服务错误时不显示成功；现有 permission 指令和域服务 POST 合同不变。本票无需前端产品修改。未生成或声称 layered、Vue/React 完整模板输出已通过构建；通用 Mapper 的 DataPermission 仍须由具体资源配置。实际 Demo 权限由真实 Mapper/MySQL 与 HTTP 验收证明。
