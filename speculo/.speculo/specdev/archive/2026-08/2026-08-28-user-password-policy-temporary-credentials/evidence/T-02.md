## 1. 实现摘要

`ClientSessionService` 现在返回匹配数、完成数与集群确认状态；Client 与 user+Client 缺失标识失败关闭。生产适配器仍只调用 Sa-Token，不硬编码 Redis key，并由 T-01 的同步确认删除合同保证远端本地缓存完成后才成功。失效中途失败会记录不含 Token 的目标/计数/异常类型，并把未确认 Token 短期限量保留以支持同目标幂等重试，即使本节点已先移除快照也不会假成功。

角色页单个/批量授权与撤销增加事务边界，集群失效失败会使关系写回滚；角色权限 Controller 的现有顺序由测试固定为 write -> resolve stored clientPk -> kick client -> success。用户页显式 Client 覆盖路径移除重复 kick，只失效该用户在目标 Client 的全部 Token。
