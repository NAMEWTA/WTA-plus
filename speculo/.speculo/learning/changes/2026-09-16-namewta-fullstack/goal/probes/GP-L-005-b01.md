## Q3 假设与反例

- objective_id: OBJ-05
- bloom_level: evaluate
- socratic_move: assumptions
- expected_evidence: `50-cde-base-dml.sql` 临时表与 DSL 块；`domains/profile` 不 import `@namewta/api-contracts`；PERSIST-006「不得互混语句类型」；变式 E；`OssService` / `UserService`
- difficulty: hard

课的隐含假设若反转，合格读者会把哪张纸认错？

1. **「复印件滞后 = generated 没有 Profile」。** 假设已假。真实剩余缺口是 **domain 还没消费生成物**：`packages/domains/profile/src/transport.ts` 从本地 `unknown` 投影，不 import `OpenApiSchema`；各资源 service 仍写死 URL。变式 E 教「快照没有这条路径时 domain 钉死暂态合同」。读者按课行事，会把已经进快照的 Profile 继续当永久分叉。这是 `D:contract-order` 的活反例：HTTP 与 transport 已在，domain 这一步没走完。
2. **「50 只放数据、两份不得互混语句类型」。** PERSIST-006 与课同句。磁盘上 50 从 L554 起有 `drop/create temporary table ..._preflight`（PASSWORD/OSS/Nacos/runtime 等块），并有带变更标识的幂等 DML（`NAMEWTA-PASSWORD-DSL-001`、`NAMEWTA-SSO-DSL-001`、`NAMEWTA-BASE-DSL-*`）。这不是产品表混进 50，但是「只放 INSERT 种子」读完会对不上文件。读者可能要么以为规则已破、往 50 里建业务表，要么把 DSL 块当成「可以另开 migrate/」。升级演练属 L-085；本格若坚持「种子权威」，至少要承认 50 = 完整最新数据基座，含回填与防护用临时表，不是 `test_demo` 十三行 INSERT。
3. **「手改 generated 会被盖掉」仍真**；「Profile 可以手写 generated」课已禁。但「快照缺口用 domain 暂态合同」在快照已补上后，暂态合同变成新的分叉许可证。
4. **「Java 兼容 = `@Deprecated` 口诀」。** 活样本有两种：`OssService` 旧方法委托式弃用；`UserService` 新能力用 `default` 空实现 / `UnsupportedOperationException`，旧抽象方法未弃用。只背注解的读者认不出第二种。
5. **「错误壳已经是前端公共合同」。** `ApiResponse` 多包复制且 `data` 可选性不一致。旧客户端只看 `code/msg/data` 的兼容故事在后端 `R` 上成立，在前端并不只有一份眼镜。

问：读完后仍说不出的，是不是「四张纸的名字」，而是 **OpenAPI 以哪份文件为立法原件、Profile 现在卡在哪一步、50 里看见 `CREATE` 时该不该报警**？
