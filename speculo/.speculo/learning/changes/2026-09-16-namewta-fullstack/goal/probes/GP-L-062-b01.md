5. **「Service 自己做 AES。」** Service 只持 `ThirdCredentialCryptoPort`。算法/nonce/AAD 在适配器。课误区 2。
6. **「想 `GET /third/credential/{id}` 再看一次明文。」** 工作树没有这个方法。Controller 零 `decrypt`。课反例 1。

9. **「已删 id 再 save 且 `enabled=true` 能复活。」** 与 missing 同一句 `"Credential not found"`，且 **不**调用 encrypt。ServiceTest 钉死。课正例 3 只写了再 remove。
10. **「`enabled=false` 的 save 等于 remove。」** 都把 delFlag 置 `"1"`、列表立刻看不见。但 save 仍要 `@NotBlank secretJson`、仍加密、仍 version+1；remove 不碰密文。
11. **「KekVersion 可以填 v2 做升级。」** 保存写死 `"v1"`；decrypt 硬编码只认 `"v1"`。课误区 5。管理切片也不会调用 decrypt。
12. **「本课覆盖 `decrypt`，所以 (d) 出站可 covered。」** decrypt 只挂在网关 `mergeCredentialHeaders`。把假设反转后，Lead 会用本行假闭合 L-064。
13. **「快照 Redis 里有一份明文凭据。」** `ThirdConfigSnapshot` 只有 Provider+Endpoint。凭据是出站当场 `findByScopes`。课图边界。
14. **「UseCase 是空转发，可以删。」** 事务注解除了 Impl 没处盖；Controller 也不得直连 Service。list 故意无事务。
15. **「厨房 `createThirdService.saveCredential` 是第四扇管理窗。」** 工厂格子归 L-065。HTTP 仍是本三扇；Summary 类型正好旁证不回显。
