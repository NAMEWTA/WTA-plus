# ADR-0058: 渠道账号独立启停，发送必须按路由选账号

- **Status:** Accepted
- **Date:** 2026-09-10
- **Source:** `2026-09-10-notify-channel-config` ADR-004（LOG-006 / LOG-007 / LOG-008）

## Context

OSS 用恰好一个默认桶。邮件发件人、短信供应商与模板码不能因为「有一个启用账号」就隐式选用。

## Decision

渠道账号独立启用或停用，允许同时启用多个。发送必须按路由解析到明确账号。禁止隐式默认账号，禁止把「任意启用账号」当作回退。本期路由不是健康度故障切换或灰度。不设独立的渠道总开关。

## Consequences

控制面必须在 Provider 调用前写入解析后的 `providerKey` / 发件账号。绑定落点见 ADR-0060。
