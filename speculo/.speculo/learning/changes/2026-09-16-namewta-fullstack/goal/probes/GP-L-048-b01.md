6. **「by-ids 格式错误返回空数组。」** HTTP 层是 fail 字符串。空白参数才是空列表。课误区 4。

11. **「这就是发送接口 / 会写 Outbox。」** 两扇只读目录。课误区 5。写出盒是 L-051/L-052。

15. **「search 是真分页，`pageNum` 有效。」** OpenAPI/Controller 都无 `pageNum`。厅堂仍传（L-053）。本课 total 是本页占用。
16. **「越权 ID 也会变成『用户编号格式错误』。」** 格式错误才是 NFE→IAE。数据范围是 `ServiceException`，那只 catch 接不住。
