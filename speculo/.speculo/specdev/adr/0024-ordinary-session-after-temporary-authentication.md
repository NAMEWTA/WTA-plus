# ADR-0024: 临时认证成功后签发普通会话

- **Status:** Accepted
- **Date:** 2026-08-29
- **Source:** `<Path>{roots.state}/specdev/archive/2026-08/2026-08-28-user-password-policy-temporary-credentials/ADR.md</Path>` ADR-003

## Context

一分钟临时密码用于管理员临时登录指定账号排查问题，只替代密码认证阶段的凭据。它不表示账号、权限或登录后的业务能力发生变化；若引入临时会话类型，新的标记与限制就必须传播到全部鉴权和业务链路。

## Decision

临时密码认证成功后完全复用普通密码登录的会话签发流程。会话不增加临时凭据标记，不缩短时长，不限制功能或权限，也不强制修改永久密码。临时凭据的特殊逻辑止于校验和原子消费边界。

## Consequences

临时密码只有 60 秒和单次使用约束，但成功后生成的 Token 按目标 Client 的正常生命周期工作。权限、角色、数据范围、退出和会话失效行为与该账号的普通登录一致，不得建立临时登录专用授权分支。
