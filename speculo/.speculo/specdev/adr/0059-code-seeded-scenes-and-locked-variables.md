# ADR-0059: 逻辑场景由代码播种，变量名随模板锁定

- **Status:** Accepted
- **Date:** 2026-09-10
- **Source:** `2026-09-10-notify-channel-config` ADR-005（LOG-011 / LOG-016 / LOG-017）

## Context

邮件可改发送内容，但变量不能改。允许管理端增删场景或改变量名会立刻让调用方 `templateParams` 与供应商审核模板失配。

## Decision

逻辑场景由代码播种。管理员可以修改邮件主题/正文、绑定渠道账号和短信供应商模板码，不能增删场景，不能改变量名。短信页不提供自由正文编辑器。邮件变量以 `${name}` 只读插入，保存时校验必填变量名未被改写。

## Consequences

首期必须播种现有生产场景。调用方继续按代码里的变量名传参。管理端改文案不得改 schema。
