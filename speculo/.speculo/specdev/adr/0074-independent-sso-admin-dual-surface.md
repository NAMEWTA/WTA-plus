# ADR-0074: 独立 SSO 管理面与客户端管理双面分工

- **Status:** Accepted
- **Date:** 2026-09-13
- **Source:** `2026-09-12-wta-sso` ADR-007（LOG-033 / LOG-034 / LOG-035）；取代 ADR-003 中「创建应用=客户端管理」产品句

## Context

旧合同把应用注册塞进「客户端管理」/仅扩展 sys_client 的同页体验，不符合产品意图，并导致管理面错位与错误 E2E。

## Decision

1. 系统管理下提供**独立「SSO 管理」模块/菜单**：创建应用、获取配置（面向自有与外部应用注册）。
2. **客户端管理**仅负责**自有 App** 的 SSO 接入配置；外部平台自配置。
3. 废止「创建应用/拿配置 = 客户端管理凑合」。
4. 数据层**仍扩展 `sys_client`**；UI 必须独立 SSO 管理。

## Consequences

管理面 AC 指向 SSO 管理模块。客户端管理不再展示「给外部建应用」主路径。与 ADR-0071 模块/数据边界互补。
