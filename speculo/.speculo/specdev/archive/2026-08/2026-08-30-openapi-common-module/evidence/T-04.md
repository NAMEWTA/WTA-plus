## 1. 实现摘要

新增由真实 `RequestMappingHandlerMapping` 构建的不可变 registry，只收录 HandlerMethod 直接声明的 `@OpenApi`。method/path 取自 Spring MVC，参数、请求和响应 schema 使用 SpringDoc 同源的 Swagger `ModelConverters`，稳定 interfaceId 由 method+path 的 SHA-256 前缀生成。缺 HTTP method/path、schema 解析失败、identity 冲突、`@SaIgnore`/`@SaCheckOr` 或非默认账号体系均失败关闭并计入 `rejectedMappings`。

共享 matcher 复现 Sa-Token 类级+方法级叠加、AND/OR、`orRole` 逗号组和 wildcard 语义。system catalog 始终先按 target userId 调用 T-03 权威 resolver，再用同一 registry/matcher 过滤；详情不可见与不存在返回同一错误。四个 GET API 分离 self 和 admin scope，admin 在权限注解之外再次确认超级管理员。目录不读取 OpenAPI credential、不创建机器 Session；cURL/Java 示例直接引用 T-01 协议常量且只含占位值。

生产组件受 `openapi.enabled=true` 条件控制；本 Ticket 未启用该属性，完整 Bean 装配由 T-12 提供。
